# 从零开始构建 AI 智能体

两天时间，从第一性原理出发构建通用智能体——包括工具调用、循环、记忆、评估测试和防护机制。

## 关于作者

Scott Moss 是一名高级工程师和教育家，专注于 JavaScript、TypeScript 和 AI 应用开发。他热衷于教授开发者如何从第一性原理出发，使用现代工具和 AI 系统进行构建。

## 关于本课程

使用 TypeScript 从零开始构建一个通用智能体。无需框架，没有魔法——只有你、一个 LLM API、一个工具感知的循环，以及让智能体在文件操作、网络搜索、代码执行等场景下可靠运行的种种模式。

你将构建一个能够编排机器上各种工具的通用智能体：读取和转换文件、调用第三方工具（如网络搜索和代码执行）、并将结果传递给本地浏览器。课程核心是智能体核心架构：一个维护对话历史、使用工具调用选择工具和参数、基于工具结果更新消息、并决定何时停止的循环。在此过程中，你将学习如何通过摘要和检索来管理上下文窗口、如何通过评估测试来捕获失败、以及如何为敏感操作添加防护机制和人工审批。课程结束时，你将拥有一个可以持续扩展新工具、协议和接口的智能体。

### 你将学到

- 理解智能体的核心原语：模型、工具、历史、记忆和编排
- 实现一个使用对话式消息的工具调用循环，而不依赖任何框架
- 以最少的额外代码接入文件系统工具、第三方工具（网络搜索、代码执行、浏览器交接）以及其他 SDK
- 通过摘要和检索管理上下文窗口，让你的智能体能够使用本地文件和搜索结果，同时不会超出 token 限制
- 设计并运行涵盖单步决策和完整多步运行的评估测试
- 为高风险工具（如 shell 命令或批量编辑）添加防护机制和人工审批
- 将智能体视为可组合的构建块，可以作为工具被调用，或接入其他系统

### 前置要求

- 熟悉 TypeScript 和 Node.js
- 能够运行本地开发服务器并管理环境变量
- 至少有一个现代 LLM 提供商的 API 密钥
- 对命令行有基本了解会有帮助，但不是必需的
