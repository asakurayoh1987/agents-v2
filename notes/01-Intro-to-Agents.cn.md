# 智能体入门

## 概述

本课介绍 AI 智能体（Agent）——它们是什么、为什么重要，以及它们擅长什么（和不擅长什么）。我们还将搭建第一个基础智能体。

## 什么是智能体？

每个人对智能体的定义都不同。这是我的定义：

**智能体是一个能够循环执行行动直到任务完成的 LLM。**

就这样。三个核心部分：

1. **LLM** - 能够推理和做出决策的语言模型
2. **行动** - 做事情的能力（调用工具、写入文件、发起 API 调用）
3. **循环** - 持续运行直到工作完成，而不是只响应一次

聊天机器人响应一次就停止。智能体会持续工作。

### 你会听到的其他定义

- "带有工具的 LLM" - 太简单了。拥有工具并不能让某物成为智能体。
- "能够实现目标的自主 AI" - 太模糊了。"自主"是什么意思？
- "能够规划和执行的 AI" - 接近了，但简单智能体不需要规划。
- "由 LLM 控制流程的系统" - 这个定义不错。LLM 决定下一步做什么。

共同点：**LLM 处于驾驶位**，决定采取什么行动以及何时停止。

## 为什么需要智能体？

单独的 LLM 受限于：
- 训练数据中的知识（可能过时、不完整）
- 单轮响应（没有持久性）
- 文本生成（对现实世界没有影响）

智能体可以：
- 访问实时数据（API、数据库、网络）
- 处理多步骤问题
- 真正地**做**事情（创建文件、发送邮件、部署代码）
- 从错误中恢复并尝试不同的方法

区别在于**代理能力**（Agency）——对世界采取行动的能力，而不仅仅是描述它。

## 智能体擅长什么

1. **重复性知识工作** - 研究、总结、数据录入
2. **代码生成和修改** - 编写、调试、重构
3. **多步骤工作流** - 需要按顺序使用多个工具的任务
4. **探索任务** - "在这个代码库中找到所有 X 并执行 Y"
5. **辅助任务** - 帮助人类提高生产力，而不是替代他们

## 智能体不擅长什么

1. **需要物理存在的任务** - 显而易见
2. **无监督的高风险决策** - 不要让智能体批准贷款或解雇员工
3. **需要人类品味的创意工作** - 它们可以起草，人类应该做决定
4. **成功标准模糊的任务** - "让它更好"但没有具体要求
5. **实时或延迟敏感的操作** - LLM 调用很慢
6. **需要真正推理的任务** - 它们是模式匹配，不是推理。复杂逻辑会失败。

最大的失败模式：**智能体自信地做错误的事情**。它们不知道自己不知道什么。

## 智能体循环

每个智能体都遵循相同的基本模式：

```
1. 接收任务
2. 思考要做什么
3. 采取行动（或响应）
4. 观察结果
5. 如果未完成，回到步骤 2
```

这有时被称为 "ReAct" 模式（推理 + 行动）。模型推理要做什么，行动，然后基于观察到的结果再次推理。

## 智能体的未来

发展方向：

- **更好的工具使用** - 模型在选择和正确使用工具方面变得越来越好
- **更长的上下文** - 更多记忆意味着更复杂的任务
- **多智能体系统** - 智能体与其他智能体协调工作
- **专业化智能体** - 针对特定领域微调的智能体（编程、研究等）
- **更好的护栏** - 更安全的智能体，知道自己能做什么、不能做什么

发展轨迹很清晰：智能体将在更少的人工监督下处理越来越复杂的任务。但我们还没到那一步。今天的智能体需要监督。

## 代码

### src/agent/run.ts

创建基础智能体运行器：

```typescript
import { generateText, type ModelMessage } from "ai";
import { openai } from "@ai-sdk/openai";

import { SYSTEM_PROMPT } from "./system/prompt.ts";

import type { AgentCallbacks } from "../types.ts";

const MODEL_NAME = "gpt-5-mini";

export async function runAgent(
  userMessage: string,
  conversationHistory: ModelMessage[],
  callbacks: AgentCallbacks,
): Promise<any> {
  const { text } = await generateText({
    model: openai(MODEL_NAME),
    prompt: userMessage,
    system: SYSTEM_PROMPT,
  });

  console.log(text);
}
```

这是最简单的"智能体"——实际上只是一个 LLM 调用。它还不是真正的智能体，因为：
- 没有工具（无法采取行动）
- 没有循环（响应一次就停止）
- 没有记忆（不使用对话历史）

我们将在后续课程中添加这些能力。

## 关键要点

1. **智能体 = LLM + 行动 + 循环** - 模型决定做什么并持续执行
2. **LLM 控制流程** - 它不仅是响应，而是在驱动
3. **智能体擅长重复性知识工作** - 不适合模糊或高风险任务
4. **从简单开始** - 基础的 LLM 调用是基础，我们将逐步添加能力

## 练习

1. **运行智能体** - 发送一条消息并查看响应
2. **更改模型** - 尝试不同的模型并比较响应
3. **修改系统提示词** - 看看它如何改变智能体的行为
